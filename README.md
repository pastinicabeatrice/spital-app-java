# Spital

Gestiunea pacienților unui spital.

## Funcționalități

- citirea pacienților (cod, nume, secție) din `pacienti.txt`
- numărul total de pacienți
- secțiile sortate descrescător după numărul de pacienți (Stream API, `groupingBy`)
- serializarea listei în `pacienti.dat` și citirea ei înapoi

## Rulare

Se deschide folderul în IntelliJ IDEA și se rulează `SpitalApp`. Directorul de lucru trebuie să fie
rădăcina proiectului, unde se află `pacienti.txt`.
